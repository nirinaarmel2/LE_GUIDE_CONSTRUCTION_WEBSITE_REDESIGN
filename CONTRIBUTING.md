# Guide de Contribution

## Règles
- Respecter la structure du projet
- Utiliser des noms de classes clairs
- Éviter le code dupliqué
- Tester le responsive avant push

## Branches
Créer une branche dédiée avant modification.

## Pull Request
Chaque PR doit contenir :
- Description
- Captures si nécessaire
- Partie modifiée
